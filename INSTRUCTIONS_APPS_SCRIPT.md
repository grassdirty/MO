# Instructiune — активируйте «NGƯƠN ĐANG ONLINE» + разбивку по браузерам

## Проблема (diagnosticată)
Старый Google Apps Script вашего сайта поддерживает **только** действие
`action=increment` (счётчик «Lượt xem»). Действия `heartbeat` / `online`
**не были реализованы на сервере** — поэтому «Đang online» всегда 0.

Сайт уже готов:
- `index.html` теперь работает в **локальном (запасном) режиме** — прямо
  сейчас он покажет ваших посетителей с вашего устройства (например
  `Chrome(1)`), и число больше никогда не застрянет на 0.
- Чтобы счётчик стал **ГЛОБАЛЬНЫМ** (видел посетителей со всего мира),
  сделайте один раз 6 шагов ниже (5 минут).

## Шаг 1 — Создайте Google Таблицу
1. Откройте **https://sheets.new** — автоматически создастся новая таблица.

## Шаг 2 — Откройте редактор Apps Script
2. В таблице: меню **«Расширения» → «Apps Script»**.

## Шаг 3 — Вставьте код
3. Удалите всё содержимое редактора и вставьте код из файла **`AppsScript_Code.gs`**
   (откройте его блокнотом/VS Code и скопируйте целиком).
4. Сохраните: **Ctrl+S**.

## Шаг 4 — Разверните как веб-приложение
5. Кнопка **«Развернуть»** (Deploy) → **«Новое развертывание»** (New deployment).
6. Нажмите на шестерёнку рядом с **«Тип веб-приложения»** (Web app).
7. **Выполнять от имени:** *Я* (Me).
8. **Доступ:** *Все / Anyone* — важно!
9. Нажмите **«Развернуть»** и подтвердите доступ
   (меню «Advanced» → «Go to ... (unsafe)» → «Allow»).

## Шаг 5 — Скопируйте URL
10. Скопируйте адрес вида: `https://script.google.com/macros/s/XXXX/exec`

## Шаг 6 — Вставьте URL в index.html
11. Откройте `index.html` и найдите строку:
    ```js
    const PRESENCE_URL = ''; // URL din AppsScript_Code.gs...
    ```
12. Вставьте скопированный адрес:
    ```js
    const PRESENCE_URL = 'https://script.google.com/macros/s/XXXX/exec';
    ```
13. Сохраните файл и выполните push:
    ```powershell
    .\git_push.ps1 "Activate global online counter"
    ```
    (или просто пришлите мне URL — я сам вставлю и запушу)

## Готово! ✅
Через 10–20 секунд в footer появится глобальная статистика:
`Đang online: 6 người • Chrome(3), Bing(2), Firefox(1)`

Счётчик обновляется каждые 20 секунд; посетитель исчезает через ~60 секунд
после закрытия вкладки.
